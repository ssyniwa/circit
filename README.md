# ⚔️ エーテル・ウォー：4大国魔導機甲戦記 (Aether War)

4つの国家が **8×8（全64マス）の領地** をかけて覇権を争う、Python / Streamlit 製のターン制魔導機甲ストラテジーゲームです。  
産業投資による資金調達、パーツを組み合わせたオリジナル魔道機甲の生産、前衛・後衛の陣形と部隊長スキルを活かした部隊編成、そして HTML5 Canvas によるリアルタイム自動戦闘アニメーションを楽しめます。

---

## 🎮 ゲームの特徴

1. **個性豊かな4大国と異なるAI戦略**
   - 🔥 **魔導技術国家メイズ**（荒れ地 / 古龍の魔結晶）：重装甲・正面突破型
   - ⚡ **サイバー科学国家システムズ**（科学都市 / プラズマ核融合炉）：経済重視・電撃拡張型
   - 🌿 **水上自然都市融合国家オアシス**（水上自然都市 / エーテルタービン）：バランス・領域防衛型
   - 🌙 **月面開拓国家ムーンライト**（月面都市 / ゼロ・ポイント機関）：少数精鋭・長距離砲撃型

2. **魔道機甲のカスタム生産＆部隊編成**
   - **4種のフレーム × 国家固有コア × 3種の装甲 × 4種の武装** を組み合わせてオリジナル機体を生産。
   - 各部隊6機（前衛3枠・後衛3枠）のポジション配置や地形適性、各部隊長が持つ固有戦力ボーナスを考慮して部隊を強化できます。

3. **HTML5 Canvas による自動戦闘シミュレーション**
   - 機体フレーム（ホバーの高速前進、重装甲のバリアなど）や搭載武装（プラズマ・キャノンのレーザー、近接ブレードの斬撃、バルカン砲など）に応じた戦闘アニメーションが再生されます。

4. **通常領地の分散拡大と、敵本拠地（🏰）への一斉総攻撃**
   - 通常領地は各部隊で分散侵攻して効率よく版図を拡大し、**敵の本拠地（🏰）を攻め落とす際は同マスに未侵攻部隊を集結させて合同総攻撃**を仕掛けるのが基本戦術です。
   - 敵本拠地を陥落させると相手国は敗北し、全領地が自国に併合されます。逆に自国本拠地を奪われるとゲームオーバーとなります。

---

## 🔄 1ターンの流れ（ゲームサイクル）

1. **フェーズ0：国家選択** — 運営する国家を1つ選択（残り3国は固有AIが運営）。
2. **フェーズ1：資金調達** — 産業レベルを強化し、毎ターンの獲得資金を増加。
3. **フェーズ2：魔道機甲生産** — パーツを選択して新鋭機を生産し、格納庫へ配備。
4. **フェーズ3：部隊編成・配置** — 格納庫の機体と部隊機体を入れ替え、前衛・後衛スロットを最適化。
5. **フェーズ4：侵攻・移動** — 自領内の移動、中立・無人領地の占領、敵駐留領地への侵攻、および敵本拠地への合同総攻撃を実行。
6. **フェーズ5：ターン結果・マップ確認** — 他国AIの行動結果と戦況ログを確認し、次のターンへ進行。

## 🚀 セットアップ・起動方法

### 必要環境
- Python 3.9 以上
- Streamlit

### インストールと実行

```bash
# 1. リポジトリをクローン
git clone https://github.com/your-username/aether-war.git
cd aether-war

# 2. 依存ライブラリのインストール
pip install streamlit

# 3. アプリの起動
streamlit run app.py
```

起動後、ブラウザで自動的に開くローカルURL（通常は `http://localhost:8501`）からプレイできます。

## 📁 ディレクトリ構成とカスタム画像対応

プロジェクト直下の `image/` フォルダに以下の命名規則で画像（`.png` / `.jpg` / `.webp`）を配置すると、ゲーム内に自動的に反映されます（未配置の場合も標準表示・代替表示で動作します）。

```text
.
├── app.py                # アプリケーション本体
├── README.md             # 本ドキュメント
└── image/                # カスタム画像フォルダ（任意）
    ├── nation_{nation_id}.png
    ├── commander_{nation_id}_corp{1..4}.png
    ├── chassis_{chassis_id}.png
    └── chassis_{chassis_id}_core_{core_id}_armor_{armor_id}_weapon_{weapon_id}.png
```

### 画像ファイル名 ID 一覧
- **`{nation_id}`**: `maze`（メイズ）, `systems`（システムズ）, `oasis`（オアシス）, `moonlight`（ムーンライト）
- **`{chassis_id}`**: `heavy`（重装甲アーマー）, `hover`（ホバリングバイク）, `buggy`（万能バギー）, `wing`（ステルス・ウィング）
- **`{core_id}`**: `dragon`（古龍の魔結晶）, `plasma`（プラズマ核融合炉）, `ether`（エーテルタービン）, `zero`（ゼロ・ポイント機関）
- **`{armor_id}`**: `standard`（標準耐熱）, `shield`（魔力収束シールド）, `titanium`（重チタン）
- **`{weapon_id}`**: `vulcan`（バルカン砲）, `cannon`（プラズマ・キャノン）, `blade`（近接ブレード）, `none`（武装なし）
